# Ozoapp

A React Native (Expo) prototype of a mobile app that helps people find discounts at restaurants in Dublin. Built in 2023.

## What's built

- **Onboarding:** swipeable intro screens with Lottie animations
- **Phone login:** phone-number input with a country calling-code picker
- **Navigation:** flow from onboarding to login with React Navigation; the code-verification screen is the next step

## Tech

React Native, Expo, React Navigation, Lottie, react-native-swiper

## Run it locally

```bash
git clone https://github.com/GabrielleGP/ozoapp.git
cd ozoapp
npm install
npx expo start
```

Then open it in Expo Go on your phone or in an emulator.
